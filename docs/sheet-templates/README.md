# スプレッドシートのセットアップ手順

このアプリは Google スプレッドシートを「データベース」として読み取ります（アプリからの書き込みはありません。編集は常にシート側で行います）。

## 1. 新しいスプレッドシートを作る

1. [Google スプレッドシート](https://sheets.new) で新規作成
2. 下部のタブを3つ用意し、名前を `members` / `goals` / `links` にする
3. 各タブに、このフォルダの CSV をインポートする
   - タブを開いた状態で「ファイル → インポート → アップロード」→ 該当CSVを選択
   - インポート場所は「現在のシートを置換する」を選ぶ
4. サンプル行は実データ投入時に書き換え・削除してOK（**1行目のヘッダーは変更しない**）

## 2. 共有設定

「共有」→「リンクを知っている全員」を **閲覧者** に設定する。
（アプリは認証なしでCSVを取得するため、この設定が必要です。組織外に知られたくない情報を載せる場合は注意）

## 3. URLを .env.local に設定

各タブを**開いた状態**でブラウザのアドレスバーのURLをコピーし、`.env.local` に貼り付ける：

```
SHEETS_MEMBERS_CSV_URL=<membersタブを開いた状態のURL>
SHEETS_GOALS_CSV_URL=<goalsタブを開いた状態のURL>
SHEETS_LINKS_CSV_URL=<linksタブを開いた状態のURL>
```

- URLに `gid=...` が含まれていることを確認（タブごとに異なる番号）
- `/edit` 形式のURLのままで構いません（アプリ側で自動的にCSVエクスポートURLへ変換します）
- 設定後、開発サーバーを再起動すると反映されます

## 各シートの列の意味

### members

| 列 | 必須 | 説明 |
|---|---|---|
| member_id | ✅ | 一意のID（例: M00001）。goals との紐付けに使用 |
| parent_id | | 紹介者の member_id。トップの人は空欄 |
| name | ✅ | 氏名。空欄の行はスキップされる |
| age | | 年齢（例: 28）。プロフィール表示用 |
| gender | | 性別（例: 男性 / 女性）。プロフィール表示用 |
| job | | 職業（例: 美容師）。メンバーカードに表示 |
| photo_url | | 写真URL。Google Driveの共有リンク可（「リンクを知っている全員が閲覧可」にする） |
| dream | | 夢・目指していること（メンバーカードの主役） |
| role | | 役職バッジ（GM など） |
| position | | バイナリー配置サイド: `left` / `right`（`L`/`R`/`左`/`右` も可）。空欄なら紹介順に左→右と交互配置 |
| updated_at | | `2026-07-15` 形式。新しい人が「新しい仲間」に表示される |

### goals

| 列 | 必須 | 説明 |
|---|---|---|
| goal_id | ✅ | 一意のID（例: G00001） |
| member_id | ✅ | members の member_id と一致させる（名前・写真が自動表示される） |
| deadline | ✅ | `2026-10-31` 形式。期限バッジと「今月のアクション」の自動判定に使用 |
| title | ✅ | 目標タイトル |
| plan_month_1〜3 | | 3ヶ月プラン。期限から逆算して今月分がハイライトされる |
| status | | `未着手` / `進行中` / `完了` / `保留` |
| updated_at | | 更新日 |

### links

| 列 | 必須 | 説明 |
|---|---|---|
| link_id | ✅ | 一意のID（例: L00001） |
| type | | `memo`（メモ）/ `qa`（Q&A）/ `attend`（アテンド）/ `other` |
| category | | 表示グループ。`定例会` はタイムライン表示になる |
| title | ✅ | リンク名。アテンドシートは「〇〇さん …」と**メンバー名を含める**と本人のプロフィールに自動紐付け |
| url | | `https://` から始まるURL。無効な場合はグレー表示 |
| sort_order | | 表示順（数字） |
| summary | | 概要。定例会メモに書くと「何を話したか」がタイムラインに表示される |
| updated_at | | `2026-07-15` 形式。定例会タイムラインの並び順に使用 |
